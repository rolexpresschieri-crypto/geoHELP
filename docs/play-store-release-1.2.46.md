# Play Store — release 1.2.46 (versionCode 67)

## File da caricare

```powershell
.\gradlew.bat bundleProdRelease renameReleaseArtifacts
```

| File | Percorso |
|------|----------|
| **AAB (Play)** | `app\build\outputs\bundle\prodRelease\geoHELP-1.2.46-release.aab` |
| APK test | `app\build\outputs\apk\prod\release\geoHELP-1.2.46-release.apk` |

Play Console → **Testa e rilascia** → **Produzione** → **Crea nuova release** → carica l’**AAB**.

Non serve modificare la descrizione lunga (già con fonti Regione/Comuni), salvo che Google lo chieda di nuovo.
