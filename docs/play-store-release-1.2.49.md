# Play Store — release 1.2.49 (versionCode 72)

Orientamento mappa allineato a SAR_TOC_GPS: in movimento la prua segue la rotta GPS, da fermo la bussola.

## Note sulla release (IT)

```
geoHELP 1.2.49

• Password dimenticata: la mail di recupero apre la schermata Nuova password
• Mappa: in movimento la prua segue la rotta GPS (da circa 4 km/h)
• Da fermo, o dopo una sosta breve, la mappa torna alla bussola
• Bussola più stabile con il telefono in mano o in verticale
• Sentieri, ordinanze, SOS e MAN DOWN invariati

geoHELP non è un ente pubblico e non sostituisce il 112.
```

## Release notes (EN)

geoHELP 1.2.49
